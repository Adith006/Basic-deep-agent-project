# Python Development

Deliver clear, maintainable Python that fits the project's existing style and dependencies.

- Inspect relevant code and configuration before changing it.
- Preserve public behavior unless the user asks for a breaking change.
- Use type hints where they clarify interfaces; validate external or untrusted input at boundaries.
- Prefer standard-library solutions unless a project dependency is already appropriate.
- Add or update focused tests when behavior changes, then run the relevant checks when available.

Read [instruction.md](instruction.md) for implementation guidance. Read [examples.md](examples.md) when choosing patterns or explaining a solution.
