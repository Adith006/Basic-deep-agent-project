# Report Writing

Produce a report that lets the reader understand the outcome, evidence, uncertainty, and next actions without reconstructing the underlying work.

- Match detail and format to the audience and request.
- Separate observed facts, assumptions, and recommendations.
- Do not invent measurements, citations, test results, or source access.
- Lead with the conclusion; use tables only when they make comparison clearer.

Read [instruction.md](instruction.md) for the reporting workflow. Read [examples.md](examples.md) for a reusable structure.
